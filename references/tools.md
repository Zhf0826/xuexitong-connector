# Xuexitong-mcp 工具参考（16 个）

所有工具均为**只读查询**，返回 Markdown 纯文本。未登录时自动尝试用环境变量或 `config.json` 登录；登录态失效自动重登一次。

## 一、登录与资料

| 工具 | 参数 | 输出 | 备注 |
|---|---|---|---|
| `login` | `phone`、`password`（均可选） | 「登录成功：姓名」 | 不传参时读环境变量/`config.json`；成功后 cookie 持久化 |
| `get_profile` | 无 | 姓名、学校、uid、fid、学年学期 | 学号字段已随接口停用，取不到 |

## 二、课表

| 工具 | 参数 | 输出 | 耗时 |
|---|---|---|---|
| `get_schedule` | `week`（可选，1 基） | 传 `week` 返回该周逐节课表（含真实日期）；不传返回全学期汇总 | 单周快；全学期需逐周拉取，约 10 秒，缓存 10 分钟 |
| `export_schedule_ics` | `save_dir`（必填）、`filename`（默认 `课表.ics`） | 落盘路径 | 用学校真实节次时间，含课前 30 分钟提醒 |

要点：服务端「不带参数只返回当前周」是接口行为，`week` 是唯一有效参数；全学期视图由客户端合并周次后压缩成 `1-16` 形式。

## 三、课程与资料

| 工具 | 参数 | 输出 |
|---|---|---|
| `list_courses` | 无 | 全部课程（课名 + courseid/clazzid/cpi），缓存 5 分钟 |
| `list_materials` | `course`、`folder_data_id`、`folder_enc` | 资料区文件列表，文件夹可逐层下钻 |
| `find_materials` | `course`、`keyword`、`max_depth`（默认 2） | 递归命中文件 |
| `download_material` | `course`、`data_id`、`save_dir`、`filename`（可选） | 落盘路径；流式写盘，大文件不占内存 |

`course` 匹配规则：课名子串匹配，精确同名优先，否则取第一个命中。同名课多时先 `list_courses`。

## 四、作业

| 工具 | 参数 | 输出 | 耗时 |
|---|---|---|---|
| `list_homework` | `course` | 序号 / 名称 / 提交状态 / 完成进度 | 快，缓存 2 分钟 |
| `get_homework_detail` | `course`、`index` | 题量、满分、作答起止时间、得分 | 快 |
| `get_homework_deadlines` | `course`（可选，限定单课）、`horizon_days`（默认 90） | 未交作业按「未来 → 已过期」排序的看板 | **慢，约 1 分钟**（逐份查详情） |

要点：

- 截止时间只存在于详情页，所以看板必须逐份请求；不要在循环里反复调用。
- 作答时间不带年份，客户端按「与今天最接近的年份」补全，跨年作业才可能排错序。
- 详情页缺失截止信息时显示「截止未知」，不是解析失败。

## 五、考试、进度、通知、云盘

| 工具 | 参数 | 输出 | 耗时 |
|---|---|---|---|
| `list_exams` | 无 | 全校考试安排：时间、时长、状态、分数 | 快 |
| `list_chapters` | `course` | 章节树 + 任务点完成情况 | 快 |
| `get_progress_overview` | 无 | 全课程进度一览，未完成多的在前 | **较慢**（逐课查询） |
| `list_notices` | `unread_only`、`limit`（默认 20）、`keyword` | 通知列表，正文摘要 160 字 | 快 |
| `list_pan_files` | `folder_id`（可选） | 云盘文件列表，支持下钻 | 快 |

要点：

- 通知列表里的 `content` 就是全文，不需要再点详情；`keyword` 实际在客户端对标题+正文过滤，范围约最近 100 条。
- 云盘只能列目录，下载受官方前端限制（文件夹/超 500MB 需客户端）。
- 章节进度里的任务点状态分三类：已完成、有 N 个待完成、未开放。

## 六、已知不可用

| 能力 | 原因 |
|---|---|
| 成绩单统计 | `stat2-ans` 页对程序化访问返回 403（WAF），改用 `get_homework_detail` 与 `list_exams` 的分数拼 |
| 学号 | 官方接口已停用 |
| 课程公告 | 无独立接口，已并入 `list_notices` |
| 站内消息（IM） | WebSocket 应用，程序化访问返回错误页 |
| 错题集 | 数据藏在压缩 JS，未解析 |
| 讨论区 | 请求参数无法从课程页稳定拼出 |
| 云盘下载 | 下载加密串由服务端 JS 生成 |

## 七、返回值形态

- 成功：多行 Markdown 文本，含表头与条目，直接朗读或二次整理即可。
- 失败：单行短消息，形如 `登录失败：xxx`、`未登录（请调用 login 工具或检查 config.json）`、`未找到课程：xxx`。
- 异常被压成单行，避免多行噪声进对话；不要期待结构化错误码，按文案判断。
